# challenge-amigo-secreto
desafio de alura 
Hola a todos los usuarios de este pequeño pero entretenido pryecto, este es un README para enender el funcionamiento basico de este programa basado en JavaScript, html y ccs.

inicialmente el programa muestra una caja de texto, un boton de agregar y otro boton de sortear amigo, con estos tres elementos se interactua

![image](https://github.com/user-attachments/assets/d8912017-7530-4542-89c8-6a20de8a4ec9)

el programa añade nombres de amigos que participan en un sorteo para saber cual es el amigo secreto, se digita el nombre de los amigos, uno a uno, en la caja de texto y se van añadiendo con el boton añadir


![image](https://github.com/user-attachments/assets/19b362ea-3f4a-4870-a4f6-fdd243d5f607)


luego este añade el amigo a una lista que va mostrando por debajo de la caja de texto, 


![image](https://github.com/user-attachments/assets/c2908e0f-75f9-4374-9377-324f1528478c)



ademas el nombre ingresado en la caja de texto es borrado, cabe resaltar que si se intenta ingresar un valor vacio, el sistema no lo dejara y pedira ingresar un valor.


![image](https://github.com/user-attachments/assets/28ed0b6c-187e-498d-b414-e02d60b81bb8)


luego de ingresar la cantidad de amigos que requiera el usuario, podra realizar el sorteo y pulsar el boton sortear amigo


![image](https://github.com/user-attachments/assets/7b529d34-2cef-431f-9675-46c4105ec669)


generando el amigo secreto


![image](https://github.com/user-attachments/assets/07cb2715-d7b1-4604-9fe8-b7082ead12c5)



si el usuario intenta pulsar el boton cuando no haya ingresado nigun amigo, el programa desplegara una alerta para solicitarle que ingrese amigos para el sorteo



![image](https://github.com/user-attachments/assets/d29bc927-85f4-474e-8132-986f1413b33b)




Espero que se diviertan con este pequeño programa
